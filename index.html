Backend API Routes

Production API Endpoints: These are the RESTful API routes that would be called in a production deployment on AWS Fargate.

Authentication & Authorization

POST /api/v1/auth/login

Authenticate clinician with SSO + MFA. Returns JWT token.

POST /api/v1/auth/refresh

Refresh expired JWT token.

POST /api/v1/auth/logout

Invalidate session and revoke token.

📁 File Upload & Storage

POST /api/v1/claims/upload

Upload audio file to Amazon S3. Returns S3 path and upload_id.

GET /api/v1/claims/upload/{upload_id}

Check upload status and retrieve metadata.

DELETE /api/v1/claims/upload/{upload_id}

Delete uploaded file (with audit log).

🎤 Speech-to-Text Processing

POST /api/v1/transcription/start

Trigger Amazon Transcribe for audio transcription.

GET /api/v1/transcription/{job_id}

Poll transcription job status and retrieve result.

POST /api/v1/transcription/{job_id}/cancel

Cancel ongoing transcription job.

🔍 HITL Gate 1: Transcription Review

POST /api/v1/hitl/transcription/approve

Medical professional approves transcription accuracy.

POST /api/v1/hitl/transcription/reject

Request corrections or re-transcription.

PUT /api/v1/hitl/transcription/{job_id}/edit

Edit transcription text with version tracking.

AI Code Extraction (Amazon SageMaker)

POST /api/v1/ai/extract-codes

Amazon SageMaker analyzes transcription and suggests CPT/ICD codes.

GET /api/v1/ai/suggestions/{claim_id}

Retrieve AI-generated code suggestions with confidence scores.

POST /api/v1/ai/feedback

Submit feedback to improve AI model (reinforcement learning).

Code Validation (DynamoDB)

GET /api/v1/codes/validate

Validate CPT/ICD codes against reference database.

GET /api/v1/codes/search

Search for CPT/ICD codes by keyword or description.

GET /api/v1/codes/compatibility

Check if CPT and ICD codes are compatible for billing.

🔍 HITL Gate 2: Medical Coding Review

POST /api/v1/hitl/codes/approve

Certified coder approves CPT/ICD code selection.

PUT /api/v1/hitl/codes/modify

Coder modifies codes with justification notes.

POST /api/v1/hitl/codes/reject

Reject codes and send back to AI for re-analysis.

AWS HealthLake (FHIR & EDI)

POST /api/v1/fhir/create-claim

Create FHIR Claim resource in AWS HealthLake.

GET /api/v1/fhir/claim/{claim_id}

Retrieve FHIR Claim resource.

POST /api/v1/edi/generate-837

Generate EDI 837 Professional claim format from FHIR data.

GET /api/v1/edi/{edi_file_id}

Download generated EDI 837 file.

🔍 HITL Gate 3: Final Billing Review

POST /api/v1/hitl/billing/approve

Billing specialist approves claim for submission.

POST /api/v1/hitl/billing/hold

Place claim on hold for additional review.

POST /api/v1/hitl/billing/reject

Reject claim and send back for corrections.

📡 Event Publishing (SNS/SQS)

POST /api/v1/pubsub/publish

Publish claim events to SNS/SQS topics for async processing.

GET /api/v1/pubsub/topics

List available SNS/SQS topics.

🚀 External Submission

POST /api/v1/clearinghouse/submit

Submit EDI 837 to external clearinghouse (Availity, Change Healthcare, etc.).

GET /api/v1/clearinghouse/status/{submission_id}

Check submission status and payer response.

GET /api/v1/clearinghouse/acknowledgment/{submission_id}

Retrieve 997/999 functional acknowledgment.

📊 Analytics (Amazon Redshift)

POST /api/v1/analytics/store

Store claim data in Amazon Redshift for analytics and reporting.

GET /api/v1/analytics/dashboard

Get practice performance metrics and claim processing statistics.

GET /api/v1/analytics/export

Export analytics data to CSV/PDF for reporting.
