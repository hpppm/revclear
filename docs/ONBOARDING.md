# Onboarding checklist (starter)

Step-by-step checklist for new contributors:

1. Read `README.md` and `DEVELOPMENT.md`.
2. Set up local Python environment (venv) for implementing services.
3. Review architecture and security docs.
4. Check the issue tracker for small starter tasks.

Additions:
- Links to cloud accounts, team Slack/Teams, and project board
- Required training for HIPAA or data handling (if applicable)
