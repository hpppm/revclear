# Security checklist (starter)

This checklist will capture security and compliance tasks for the cloud prototype.

- Authentication & Authorization: Role-based access design
- Audit logging: central logging and retention policy
- Encryption: TLS in transit, at-rest encryption for data stores
- Secrets management: use a cloud KMS/secret manager
- Compliance: HIPAA-related controls to review

Next steps:
- Map controls to cloud services (e.g., AWS KMS, GCP KMS, Azure Key Vault)
- Define data retention and anonymization strategy for research/demo data
