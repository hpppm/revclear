🔌 Backend API Routes

ℹ️ Production API Endpoints: These are the RESTful API routes that would be called in a production deployment on AWS Fargate.

🔐 Authentication & Authorization

POST /api/v1/auth/login - Authenticate clinician with SSO + MFA

POST /api/v1/auth/refresh - Refresh expired JWT token

POST /api/v1/auth/logout - Invalidate session and revoke token

📁 File Upload & Storage

POST /api/v1/claims/upload - Upload audio file to Amazon S3

GET /api/v1/claims/upload/{upload_id} - Check upload status

DELETE /api/v1/claims/upload/{upload_id} - Delete uploaded file

🎤 Speech-to-Text Processing

POST /api/v1/transcription/start - Trigger Amazon Transcribe

GET /api/v1/transcription/{job_id} - Get transcription result

POST /api/v1/transcription/{job_id}/cancel - Cancel transcription
